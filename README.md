# CODE HEADS

## Sobre o projeto

Este projeto será desenvolvido pelo time **CODE HEADS** utilizando tecnologias
web fundamentais, sem frameworks ou bibliotecas externas. A proposta é criar
uma aplicação simples, organizada e acessível, usando apenas HTML 5, CSS e
JavaScript vanilla.

## Stack escolhida

### HTML 5

O HTML 5 será responsável pela estrutura e pelo conteúdo da aplicação. Serão
utilizados elementos semânticos, como `header`, `nav`, `main`, `section`,
`article` e `footer`, sempre que forem adequados. Essa organização facilita a
acessibilidade, a manutenção do código e a interpretação da página pelos
mecanismos de busca.

### CSS

O CSS será utilizado para definir a apresentação visual da aplicação,
incluindo:

- cores, tipografia e espaçamentos;
- organização dos elementos na tela;
- layouts responsivos para diferentes tamanhos de dispositivo;
- estados visuais de botões, links, formulários e outros componentes;
- animações e transições, quando forem necessárias.

Os estilos devem ficar separados da estrutura HTML para manter o projeto
organizado e facilitar futuras alterações no visual.

### JavaScript vanilla

O JavaScript será utilizado sem frameworks ou bibliotecas externas. Ele ficará
responsável pela interatividade e pelo comportamento da aplicação, incluindo:

- manipulação do DOM;
- validação e envio de formulários;
- tratamento de eventos;
- atualização dinâmica do conteúdo;
- comunicação com APIs, caso o projeto precise desse recurso.

## Como rodar o projeto localmente

### Pré-requisitos

- Git instalado;
- um navegador atualizado, como Google Chrome, Mozilla Firefox, Microsoft
  Edge ou Safari;
- um editor de código de sua preferência, como Visual Studio Code.

Não é necessário instalar Node.js, npm ou outras dependências enquanto o
projeto utilizar somente HTML 5, CSS e JavaScript vanilla.

### Passo a passo

1. Clone o repositório:

   ```bash
   git clone https://github.com/ItaloSilvaHAS/ProjetoHackton
   ```

2. Entre na pasta do projeto:

   ```bash
   cd ProjetoHackton
   ```

3. Abra o arquivo `index.html` no navegador.

   Também é possível abrir a pasta no Visual Studio Code e iniciar o projeto
   com uma extensão de servidor local, como o **Live Server**.

### Executando com um servidor local

Para evitar limitações do navegador ao carregar arquivos locais e simular um
ambiente mais próximo da publicação, também é possível iniciar um servidor
HTTP simples com Python:

```bash
python3 -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000
```

Para encerrar o servidor, pressione `Ctrl + C` no terminal.

> **Observação:** o repositório está em fase inicial e, no momento, contém a
> documentação do projeto. Assim que o arquivo `index.html` e os demais
> arquivos da aplicação forem adicionados, os passos acima poderão ser usados
> para executá-la localmente.
